## 4. Exploit Notes

### Current Exploit Approach

The current exploit code (`win32k_uaf_exploit.cpp`) uses **compile-time preprocessor
defines** to select the correct addresses for each Windows version. It does NOT
dynamically scan for the signature at runtime.

### Runtime Signature Scanning (Future Enhancement)

For maximum portability, the exploit could be enhanced to:
1. Load `win32kfull.sys` from disk into usermode memory
2. Scan for the signature `48 8B ?? 28 F6 41 12 04 0F 85`
3. Identify which function contains the match (by checking surrounding bytes)
4. Auto-detect the register used (from the ModRM byte)
5. Auto-detect the correct offsets for that build
6. Dynamically construct the exploit parameters

This would make the exploit work on ANY Windows version without recompilation.
